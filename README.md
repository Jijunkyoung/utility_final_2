# Facility AI — 유틸리티 설비·에너지 통합 관리

**기획** 지준경 · HD 생성형 AI 업무자동화 전문가과정 1차수 (Day05 프로젝트 15)
**주소** <https://aebonlee.github.io/hd-project15/>

캠퍼스 안 유틸리티 설비를 대장으로 관리하고, 법정검사·소모품 교체 시기를 계산하고,
이력과 금액을 쌓아 차년도 비용을 예측하고, 월별 에너지 고지서에서 사용량을 뽑아 봅니다.

### Issue #2 — 설비 상세 통합

설비 목록의 **상세** 버튼에서 해당 설비 ID에 연결된 자료만 한 번에 관리합니다.

- **설비 등록** — 목록 위 버튼에서 창을 열고, 라벨은 왼쪽·입력칸은 오른쪽으로 한 줄씩 입력
- **기본정보** — 제조사·모델·용량·유량·압력·소비전력·설치일을 포함한 사양 수정
- **소모품** — 교체주기·최근교체일·예정일·상태·단가 저장 및 일정 계산
- **이력** — 설비별 복수 법정검사를 구분해 완료일·주기·비용을 관리하고 유지보수·고장 AS·소모품 교체 이력 저장
- **매뉴얼** — 원본을 공유폴더에 저장하고 요약·소모품 교체주기·검사주기 제안 생성
- **법령** — 후보를 내부 DB에 저장하고 원문·적용 조항과 설비 사양의 비교 검토표 생성
- **검토기록 자동 작성** — 비교표 행을 누르면 법령명·상세 요구사항·확인정보를 채우고 담당자는 검토결과만 기록
- **연관법령 직접 추가** — 자동 후보에 없는 법령도 설비별로 법령명·연관 내용·출처·기준일·적용 조항을 등록
- **법령 개정 확인** — 저장한 모든 연관법령의 최신본을 각각 확인하고, 변경 문장·누락 사양·검토 상태를 이력으로 보존

법령 후보와 변경 비교는 **적용 확정이나 법률 판단이 아니며 검사주기도 만들지 않습니다.**
API가 설정되면 국가법령정보센터 최신본을 확인하고, 폐쇄망에서는 사용자가 올린 최신 파일이나
붙여넣은 원문을 이전 보존본과 비교합니다.

## 안전 원칙

AI와 외부 API를 연결하더라도 다음 원칙은 지킵니다.

### 1. 법령만 보고 검사 주기를 확정하지 않습니다

같은 "보일러"라도 용량·종별·설치 장소에 따라 법정검사 주기가 다릅니다.
숫자 하나를 미리 박아 두면 **그럴듯해 보이고, 그래서 아무도 다시 확인하지 않습니다.**
틀린 주기로 법정검사를 놓치면 그건 실제 피해입니다.

그래서 설비 종류만으로 주기를 만들지 않습니다. 저장한 법령 원문과 매뉴얼에서 근거 문장을
찾아 제안하되, 사용자가 확인하고 누른 값만 반영합니다. 주기가 비어 있으면 “주기 없음”으로
표시되고 개요의 **확인 필요** 목록에 올라옵니다.

### 2. 외부 연결은 설정한 경우에만 사용합니다

법령 API와 외부 AI는 사내 서버에 주소·인증값을 설정한 경우에만 호출합니다. 기본값은
**규칙 기반 분석**이며 로컬 AI를 우선할 수 있습니다. API 키는 GitHub나 브라우저에 저장하지 않습니다.

대신 이렇게 합니다.

- **법령 수집·검토** → 후보를 내부 DB에 저장하고, API가 설정되면 원문을 받아 설비 사양과 비교합니다.
- **매뉴얼 분석** → PDF·텍스트·CSV·엑셀 본문을 규칙 또는 AI로 분석하고 사용자가 승인할 일정만 반영합니다.
- **알림 메일 발송** → 임박 항목을 승인 대기함에 넣고 담당자가 승인한 건만 사내 SMTP로 발송합니다. SMTP 미설정 시 문안을 복사합니다.

자동 발송 대신 할 일 목록이 되는 셈인데, 폐쇄망에서도 돌고
틀린 법령 정보가 자동으로 퍼질 위험도 없습니다.

## 폐쇄망과 허용된 외부 API를 모두 지원합니다

기본 기능은 외부 연결 없이 동작합니다. 사내 보안 승인을 받은 경우에만 설정 화면에서
국가법령정보센터 또는 외부 AI API를 켤 수 있습니다.

- 엑셀 읽기·쓰기 — `lib/xlsx.full.min.js`
- PDF 글자 뽑기 — `lib/pdf.min.mjs` + `lib/cmaps/` (한글 PDF 를 읽으려면 cMap 이 필요합니다)
- 그래프 — 라이브러리 없이 SVG 로 직접 그립니다
- 글꼴 — OS 기본 글꼴 (Windows 맑은 고딕 / macOS Apple SD Gothic Neo)

확인하려면 저장소 루트에서:

```sh
python3 -m http.server 8899
# 다른 창에서
node ../hd-04/scripts/probe.mjs /hd-project15/ /hd-project15/energy.html …
```

`probe.mjs` 는 **localhost 말고 전부 차단한 크롬**으로 실제로 열어 봅니다.
여기서 뜨면 폐쇄망에서도 뜹니다.

## 자료는 어디 있나

사내 보조 서버를 실행하면 원본 파일은 지정한 UNC 공유폴더에, 설비·담당자·이력·에너지와
법령·파일·분석 메타데이터는 같은 위치의 SQLite DB에 저장됩니다. 서버 연결 전에는 화면 검토용
자료가 브라우저에 임시 저장됩니다.

저장 자료는 설비·담당자·소모품·이력·매뉴얼·법령검토·법령버전·법령변경·에너지·건물좌표 컬렉션으로 분리되어 있고,
예전 v1 JSON을 가져오면 새 컬렉션과 건물 좌표를 자동으로 보완합니다.
설비를 삭제하면 해당 설비 ID에 연결된 소모품·이력·매뉴얼·법령검토 자료도 확인 후 함께 삭제됩니다.

- 먼저 Windows에서 `server/start_server.bat`를 실행하고 `http://127.0.0.1:8765`에서 검증합니다.
- 여러 PC 공개는 IT 승인과 접근 토큰 설정 뒤 `server/start_server_lan.bat`를 사용합니다.
- 화면은 서버 주소에서 직접 열고 `\\fileserver\facility\FacilityAI` 같은 UNC 경로를 입력합니다.
- `공유폴더 읽기·쓰기 시험`을 통과한 뒤 매뉴얼·법령 파일을 업로드합니다.
- 다른 PC가 먼저 저장하면 자동 덮어쓰지 않습니다. 설정에서 사용할 자료를 확인해 선택합니다.
- 보조 서버를 쓰지 않는 PC에서는 JSON 내보내기·가져오기로 임시 자료를 이동할 수 있습니다.

## 조심할 것 — 모르는 값을 0 으로 채우지 않습니다

이 도구가 가장 신경 쓴 부분입니다.

| 상황 | 흔한 처리 | 여기서는 |
|---|---|---|
| 이력의 금액을 모름 | 0 원 | **미상** — 합계에서 빼고 건수로 따로 표시 |
| 비용 예측에 단가가 없음 | 0 원으로 합산 | **“셀 수 없었던 것”** 목록에 이유와 함께 |
| 마지막 검사일이 없음 | 오늘 기준으로 계산 | **“이력 없음”** — 날짜를 지어내지 않음 |
| 고지서에서 못 읽은 달 | 0 으로 그래프 바닥 | **행을 만들지 않음** + 몇 줄을 못 읽었는지 알림 |

0 으로 채우면 합계가 멀쩡해 보이고 **어디에도 표가 나지 않습니다.**
예산을 실제보다 적게 잡거나, "3월에 전기를 안 썼다"는 그래프를 보고 원인을 찾으러 다니게 됩니다.

## 개발

```sh
node test/logic.test.js     # 날짜·법령·매뉴얼·공용 저장·에너지 규칙 검사 (108개)
python3 test/jobs.test.py   # 자동 알림·법령 변경 기록 검사 (3개)
python3 test/server.test.py # 공유 DB 충돌·백업·복원·권한·SMTP 검사 (13개)
node test/smoke.browser.js  # 열 화면과 주요 흐름을 실제로 띄운다
python3 build.py            # 페이지 열 개를 다시 굽는다
```

둘 다 CI(`.github/workflows/test.yml`)에서 자동으로 돕니다. `build.py` 는 다시 구운
결과가 커밋된 HTML 과 같은지까지 봅니다 — 페이지를 손으로 고치면 여기서 걸립니다.

왜 이렇게 만들었는지는 [`docs/개발일지.md`](docs/개발일지.md), 작업 규칙은
[`CLAUDE.md`](CLAUDE.md) 에 있습니다.

**페이지를 손으로 고치지 마세요.** `build.py` 가 덮어씁니다.
본문은 `build.py` 의 `PAGES` 에, 머리말·메뉴는 `HEAD`/`MENU` 에 있습니다.

### 왜 날짜를 따로 검사하나

날짜는 **눈으로 검산하기 어렵습니다.** 이틀 밀린 것을 화면에서 알아채기는 거의 불가능한데,
이 시스템에서 이틀은 "법정검사 기한을 넘겼는가"를 가릅니다.

가장 흔한 함정은 **말일**입니다. 1월 31일 + 1개월을 그냥 더하면 2월에 31일이 없어
**3월 3일**이 됩니다. 검사 주기가 조용히 이틀 밀립니다.

검사기를 만든 뒤 **일부러 여섯 가지를 깨뜨려** 전부 잡히는 것을 확인했습니다
(말일 처리 제거 / 이력 없는데 "여유" / 한 해 여러 번을 한 번으로 / 13월 통과 /
요금 없음을 0원으로 / 법령표에 주기 지어내기).

## 남은 것

- **현장 자료 입력** — 실제 설비·담당자·매뉴얼·검사·고지서 자료와 캠퍼스 조감도 이미지가 필요합니다.
- **사내 운영 승인** — 공유폴더 권한, 서버 포트, SMTP, OCR·법령·AI 외부 API 허용 여부를 보안 담당자와 확인해야 합니다.
- **Windows 작업 등록** — 회사 PC에서 `server/run_jobs.bat`를 매일 실행하도록 작업 스케줄러에 등록해야 합니다.
