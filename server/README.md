# Facility AI 사내 보조 서버

브라우저가 직접 접근할 수 없는 사내 공유폴더와 AI 연결을 담당합니다. Python 표준
라이브러리만 사용하며 별도의 패키지 설치는 필요하지 않습니다.

## Windows 실행 — 이 PC에서 먼저 검증

1. Python 3.11 이상을 설치합니다.
2. `config.example.json`을 `config.local.json`으로 복사하고 공유폴더 경로를 입력합니다.
3. 이 폴더의 `start_server.bat`를 실행합니다. 기본 주소는 `http://127.0.0.1:8765`입니다.
4. 그 주소를 브라우저에서 엽니다. 화면과 API가 같은 주소라 CORS·혼합 콘텐츠 문제를 줄입니다.
5. 설정에서 `공유폴더 읽기·쓰기 시험`을 누릅니다.

실행 계정에 해당 UNC 공유폴더의 읽기·쓰기 권한이 있어야 합니다. 드라이브 문자보다
`\\fileserver\facility\FacilityAI` 같은 UNC 경로를 권장합니다.

실제 설정과 API 키는 Git에 포함되지 않는 `config.local.json`에 저장됩니다. 회사의
Windows 권한으로 이 파일을 관리자만 읽을 수 있게 제한하세요.

## 사내 메일 알림

알림 화면에서 승인된 건만 사내 서버를 통해 발송할 수 있습니다. `config.local.json`에
`smtpHost`, `smtpPort`, `smtpFrom`을 설정하고, 인증이 필요한 경우에만 `smtpUser`와
`smtpPassword`를 입력합니다. 회사 메일 서버가 TLS를 지원하면 `smtpStartTls`를 `true`로
유지하세요. 비밀번호는 브라우저·공용 DB·GitHub로 보내지 않으며 이 서버 설정 파일에서만 읽습니다.

SMTP 정보는 회사 IT 담당자에게 확인하세요. 보안프로그램이나 방화벽을 우회하거나 임의 포트를
개방하지 말고, 메일 서버 접속이 승인되지 않은 경우 알림 문안을 복사해 수동 발송합니다.

## 여러 PC에서 사용하기

`start_server_lan.bat`는 회사 IT/보안 담당자가 포트 사용과 Windows 방화벽 정책을 승인한
뒤에만 실행합니다. 실행 전 `config.local.json`의 `apiToken`에 충분히 긴 임의 문자열을
반드시 지정해야 하며, 없으면 서버가 LAN 공개를 거부합니다. 각 PC는 같은 토큰을 설정 화면에
입력합니다. 토큰은 해당 PC 브라우저에만 저장되고 공용 DB나 서버 설정 API에는 저장하지 않습니다.

- 설비·이력·에너지·담당자 자료는 공용 SQLite DB에 버전과 작업자 기록을 남깁니다.
- 다른 PC가 먼저 저장했으면 자동 덮어쓰지 않고 충돌을 알립니다.
- `공용 DB 지금 백업`은 지정한 공유폴더의 `backups` 아래에 시각별 복사본을 만듭니다.
- 외부 AI와 법령 API는 설정하기 전에는 호출하지 않습니다.
- SQLite 파일은 이 서버 한 대만 열어야 합니다. 여러 서버 프로세스를 같은 공유폴더에 연결하지 마세요.

관리자 권한 설치나 보안 프로그램 우회는 필요하지 않습니다. 방화벽 예외가 필요하면 임의로
추가하지 말고 IT 담당자에게 `TCP 8765`의 서버 PC→사내 허용 범위를 확인받으세요.

## AI 방식

- 로컬 AI: Ollama 호환 `/api/generate`를 사용합니다.
- 외부 AI: OpenAI 호환 `/v1/chat/completions` 주소를 사용합니다.
- 자동 선택: 로컬 AI를 먼저 호출하고, 설정에서 명시적으로 허용한 경우에만 외부 API로 넘어갑니다.
- 규칙 기반: 서버와 AI가 없어도 브라우저에서 보수적인 추출을 수행합니다.

자동 분석은 담당자 검토 보조용입니다. 법적 적합 여부와 검사주기를 최종 확정하지 않습니다.
