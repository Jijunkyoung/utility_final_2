# Facility AI 사내 보조 서버

브라우저가 직접 접근할 수 없는 사내 공유폴더와 AI 연결을 담당합니다. Python 표준
라이브러리만 사용하며 별도의 패키지 설치는 필요하지 않습니다.

## Windows 실행

1. Python 3.11 이상을 설치합니다.
2. 이 폴더의 `start_server.bat`를 실행합니다.
3. 웹 화면의 **설정**에서 서버 주소를 `http://서버PC이름:8765`로 입력합니다.
4. UNC 공유폴더 경로를 입력하고 `공유폴더 읽기·쓰기 시험`을 누릅니다.

실행 계정에 해당 UNC 공유폴더의 읽기·쓰기 권한이 있어야 합니다. 드라이브 문자보다
`\\fileserver\facility\FacilityAI` 같은 UNC 경로를 권장합니다.

실제 설정과 API 키는 Git에 포함되지 않는 `config.local.json`에 저장됩니다. 회사의
Windows 권한으로 이 파일을 관리자만 읽을 수 있게 제한하세요.

## AI 방식

- 로컬 AI: Ollama 호환 `/api/generate`를 사용합니다.
- 외부 AI: OpenAI 호환 `/v1/chat/completions` 주소를 사용합니다.
- 자동 선택: 로컬 AI를 먼저 호출하고, 설정에서 명시적으로 허용한 경우에만 외부 API로 넘어갑니다.
- 규칙 기반: 서버와 AI가 없어도 브라우저에서 보수적인 추출을 수행합니다.

자동 분석은 담당자 검토 보조용입니다. 법적 적합 여부와 검사주기를 최종 확정하지 않습니다.
